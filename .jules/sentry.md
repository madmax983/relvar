## 2026-05-01 - Tuple Grouping and Summarization Attribute Not Found Error Maps
**Learning:** Functions like `group`, `summarize`, and `ungroup` internally iterated and used `.unwrap()` on `tuple.get(attr)` under the assumption that the validated relation type strictly guaranteed attribute presence. While this is mathematically true in the pure relational model, any internal inconsistency, malformed tuples bypassing validation, or memory corruption could trigger an unhandled panic in production.
**Action:** Replaced `.unwrap()` calls in `group.rs` and `summarize.rs` with `.ok_or_else(|| ...)` explicitly mapping to `GroupError::AttributeNotFound` and `SummarizeError::AttributeNotFound`, respectively. Always prefer robust Result propagation over panics, even for seemingly "guaranteed" schema invariants.
## 2024-05-01 - Scalar Type and Value Missing Branches
**Learning:** Found several unreachable paths (`_ => unreachable!()`) in ordering and equality methods inside `relvar-core/src/types/scalar.rs` and `relvar-core/src/values/scalar.rs` that weren't covered. This included deep recursive type checking, serialization, hash methods on boolean/string types, and float equality branches including `NaN`. Internal private modules also required testing bounds via direct internal module definition tests.
**Action:** Created `sentry_scalar_coverage_final.rs` test that exercises these specific gaps covering `UserDefined` recursive checking, Ord logic, Float bits checks, and Serialization coverage pushing the core library coverage higher. Modified internal module definitions to catch unreachable error conditions during recursive parsing.
