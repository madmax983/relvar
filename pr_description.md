🗺️ Atlas: [Module Privacy Cleanup]

🕸️ Tangle: The codebase had multiple public module declarations (`pub mod`) across internal namespaces (e.g. `relvar-core/src/database/tests/mod.rs`, `relvar-core/src/query/tests/mod.rs`, `relvar-storage/src/persistent_engine/tests/common.rs`, `relvar-core/src/query/tests/common.rs`), leaking test infrastructure and common test helper functions as public APIs, resulting in poor encapsulation and muddying dependency boundaries. Also, `tools` module in `relvar` was incorrectly marked as `pub(crate)` which broke public-facing external integration test logic, and `PAGE_SIZE` in `relvar-storage/src/storage/mod.rs` was not publicly exported, causing failing benchmarks.
📐 Blueprint: Converted public module definitions in test and internal directories to private (`mod`) or crate-private (`pub(crate) mod`). Modified shared test helper functions from `pub fn` to `pub(crate) fn` to ensure test implementations remain fully internal. Re-exported `tools` and `experimental` publicly in `relvar/src/lib.rs` and re-exported `PAGE_SIZE` in `relvar-storage/src/storage/mod.rs`. Suppressed unused code warnings on the experimental modules by prepending `#[allow(dead_code)]`. Added back necessary `pub mod storage` and `pub mod persistent_engine` in `relvar-storage/src/lib.rs`.
🧱 Stability: Strict separation enforced; test utilities are no longer accidentally leaked to consumers. Faster compile times and cleaner IDE discovery, whilst keeping tests unbroken.
🔬 Verification: Builds successfully, all tests pass, and strictly adheres to the rule of using `pub(crate)` by default for modules without breaking existing dependencies.
