Title: 🌟 Nova: Relational Quantum Circuit Simulator

💡 **The Spark:** "Can we model quantum computing using relational algebra?"
🚀 **The Feature:** "Implemented a Relational Quantum Circuit Simulator (`QuantumState` and `QuantumGate`). Models complex amplitudes as relations. Includes basic gates (Hadamard, Pauli-X, CNOT) and applies them via matrix multiplication (Join, Extend, Summarize)."
🔮 **The Potential:** "Could be used for small-scale quantum state tracking, educational simulations, or combining quantum logic with relational search algorithms."
⚠️ **Risk:** "Low. Isolated in `src/experimental/quantum.rs`."
