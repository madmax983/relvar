💡 **The Spark:** I noticed we could use transitive closure (`tclose`) combined with standard algebra operators to perform Mark-and-Sweep Garbage Collection declaratively.
🚀 **The Feature:** Implemented `GarbageCollector` which models roots, heap, and references as pure relations.
🔭 **The Potential:** Demonstrates how memory management can be implemented without procedural traversal algorithms.
⚠️ **Risk:** Low. Isolated in `src/experimental/garbage_collector.rs`.
